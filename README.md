# Smart Exam Attendance & Monitoring System

A web-based solution inspired by the national fuel QR system to streamline the examination attendance process using QR technology and real-time cloud data.

## Project Overview
Traditional exam attendance involves manual signatures, which can be time-consuming and prone to identity fraud. This system digitizes the process by providing examiners with a web-based QR scanner to verify student identities and record attendance instantly.

## Key Features
* Web-Based QR Scanner: Works on any smartphone (Android/iOS) via a web browser.
* Real-Time Verification: Instantly fetches and displays student photos, names, and subjects from the database.
* Live Dashboard: Provides supervisors with a real-time summary of present and absent students.
* Cloud Integration: Powered by Firebase for secure and instant data synchronization.

## Technology Stack
* Frontend: HTML5, CSS3, JavaScript
* Backend/Database: Firebase Realtime Database
* Hosting: GitHub Pages
* Libraries: HTML5-QRCode
